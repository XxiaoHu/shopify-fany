# 黑五变体商品网格

在主题编辑器「添加分区」中选择 **黑五变体商品网格**。本次只注册 section，未加入模板或现有页面。

## 配置

- 每张「商品卡片」独立填写颜色版本链接，直接粘贴商品页选好颜色后的完整地址（包含 `?variant=...`），无需再选商品。
- 商品标题、展示售价、展示划线价、优惠标识金额全部手动填写。金额按原样显示，包含货币符号；留空隐藏，不读取商品价格或自动计算优惠。卡片标题留空会隐藏，不自动读取商品标题。
- PC 与移动端图片可独立上传。图片优先级：自定义移动图（移动端）→ 自定义 PC 图 → 链接对应颜色图片 → 商品主图。两端响应式图片与焦点相互独立。没有下载或预设设计稿商品图片。
- 商品和变体数据只用于链接识别、库存、实际加购，以及未上传图片时的图片回退。购物车 / 结账使用 Shopify 后台的实际商品价格。
- 加购成功跳转购物车；Buy Now 直接进入对应颜色的商品详情页，不加购、不进入结账。缺货时禁用加购，但保留详情入口；无效链接不会加到其他颜色。
- 顶部 PC 与移动端的标题和说明可以分别配置；移动端字段留空时回退 PC。顶部图片可替换，默认复用 Flash Deal 原图；PC 星光装饰可以关闭。没有实现持续动画。
- 标题、说明、卡片文案的字号 / 行高、卡片间距、图片与标题间距、标题与说明间距、标题区与卡片间距、颜色及两端上下留白均可配置。
- 导航锚点默认 `best-sellers`，与黑五专属导航的目标锚点保持一致即可。多个模块请使用不同锚点。

## 布局与数量

- PC 设计节点 `6411:24800`：1920px，左右 200px，4 列，列间距 16px、行间距 40px；图片 368 × 458px，卡片 368 × 649px。
- 移动设计节点 `6411:25869`：393px，左右 16px，2 列，列间距 11px、行间距 20px；图片约 175 × 217.57px，卡片约 175 × 349.57px。
- 1440px 以下使用两列，1068px 以下桌面侧边距为 32px；749px 以下采用移动端样式。
- PC 稿有 16 张示例卡片，移动稿有 6 张；实现按真实 blocks 全部显示，不截断移动端卡片，也不限制固定数量。preset 提供 PC 的 16 张示例文案；正式页面只输出已配置链接的卡片，主题编辑器显示未配置卡片的占位图与禁用按钮。

## 代码复用与验证

入口：`sections/black-friday-product-grid.liquid` 与 `assets/black-friday-product-grid.css`。

标题区复用 `black-friday-promo-heading`；商品卡片通过 `card_layout: 'grid'` 复用 `black-friday-gift-sets-card`；购买行为复用 `assets/black-friday-gift-sets.js`。网格样式只作用于自己的根类，其他礼盒模块继续使用原来的布局和标识尺寸。

资源仅新增桌面星光 PNG 与移动端小优惠标识背景。PC 优惠标识使用既有的 78px 版本，保持 SVG 的原始尺寸。

链接识别使用 Shopify `all_products`，每页最多查询 20 个不同商品 handle（同商品多颜色复用同一 handle），这是平台限制，不是 blocks 数量限制。

本地验证涵盖 1920 / 1280 / 750 / 749 / 393 / 320px、PC / 移动端标题、手动金额、图片回退及切换、空字段、长标题、33 张卡片、缺货及无效链接、模拟加购和错误重试、Buy Now / 键盘 / 移动触摸、多个实例、与原礼盒模块同页和原模块回归。没有向真实商店提交购物车或订单。
