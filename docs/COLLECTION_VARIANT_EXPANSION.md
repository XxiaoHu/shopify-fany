# 集合列表按 SKU 展开展示

## 后台配置

1. 在 Shopify 后台的「设置 → 自定义数据 → 产品」（部分版本显示为「元字段和元对象 → 产品」）添加产品元字段定义。
2. 名称填写「列表展开全部 SKU」，命名空间和键填写 `custom.expand_variants`，类型选择「真或假 / Boolean」。必须是产品级元字段，不是变体级元字段。
3. 打开需要展开的商品，将这个元字段设为「真」并保存。未填写或设为「假」的商品保持一张普通商品卡片。
4. 将修改后的主题文件同步到正在预览或使用的主题。无需在主题编辑器额外开启总开关，集合列表直接根据商品元字段决定是否展开。

主题代码读取这个元字段，但不会自动创建 Shopify 后台的元字段定义，也不会修改商品数据或模板配置。

如果配置后仍未展开，检查元字段定义的命名空间和键是否确实为 `custom.expand_variants`（显示名称相同不代表键相同），并确认代码已同步到当前查看的主题。此前版本中额外的 `enable_variant_expansion` 总开关已移除。

## 前台行为

- 已开启的商品按后台变体顺序，每个变体显示一张卡片；只有默认变体的商品仍按普通商品显示。
- 每张卡片显示商品名称和规格组合、变体价格及划线价，优先使用变体图片，没有时回退商品主图。
- 售罄变体仍展示，并优先标记「售罄」，不被商品级 Best Seller 标签覆盖。
- 卡片链接使用变体 URL，进入详情页后选中对应 SKU。
- 普通快速加购加入当前 SKU；有数量规则或必须选择订阅计划的商品，打开预选该 SKU 的购买弹窗。批量快速加购使用当前 SKU 的数量规则；必须选择订阅计划的商品通过详情页购买。
- 保留网格列数、响应式样式、商品标签、评分、悬停图片和 Shop now 样式。未传入变体的其他页面继续使用原商品卡片流程。

## 分页、筛选与容量

- 集合的分页、排序、筛选及商品统计仍按商品计算，不按展开后的卡片数量计算。因此每页实际卡片数可能大于「每页商品数」。
- 同一商品的 SKU 相邻展示；筛选匹配商品后仍展示该商品的所有可读取 SKU，不额外按变体条件过滤。
- 变体按每批 50 项循环，避免单个 Liquid 循环的迭代限制。此处不嵌套 `paginate`，避免影响集合页码。
- Shopify 的 `product.variants` 未分页时最多返回 250 个变体。超过此数量时，列表展示可读取的变体，并额外提供「商品名称 — 查看完整详细信息」入口。若业务需要在集合列表直接展开超过 250 个 SKU，需要另做变体分页加载，当前实现不声称覆盖这个场景。

平台依据：[product.variants](https://shopify.dev/docs/api/liquid/objects/product#product-variants)、[Liquid for](https://shopify.dev/docs/api/liquid/tags/for)。
