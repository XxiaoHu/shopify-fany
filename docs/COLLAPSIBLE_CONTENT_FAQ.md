# 可选黑五 FAQ 样式

在现有「可折叠内容 / FAQ」分区顶部，开启 **启用黑五 FAQ 样式**，当前分区即可使用新设计。开关默认关闭，不会自动替换现有页面的样式，也没有修改任何模板。

## 配置

- 标题、说明、问题、富文本回答和关联页面内容继续使用原有字段，没有替换已有文字。设计稿中的 `FAQ` 请在当前分区标题中自行填写。
- 问答字号和字重继续使用原有 PC / 移动端「问答字体」设置。
- 新样式的背景、标题、问题、PC / 移动端回答颜色、标题发光和标题字号，在新增设置中维护，不改变原有标题颜色和移动端标题字号的默认值。
- 新样式可分别调整 PC / 移动端的标题与问题间距、问题组间距、问题与回答间距，以及整个分区上下留白。上下间距均可设为 0。
- 每个问题新增「黑五样式中默认展开此问题」，默认关闭；原「展开第一项」仍可使用。多个问题可以同时展开，图标随状态切换加号 / 减号。原样式不使用这个新增的逐项开关。
- 导航锚点默认 `faq`，可与黑五导航目标匹配；多个实例请使用不同锚点。
- 黑五样式使用独立的纯问答布局。原来的图片、行首图标、布局、标题内外位置、分割线和旧间距设置继续保留，供默认样式使用；切回默认样式即可恢复。

## 兼容方式

原有所有设置 ID、默认值、block 设置和 preset 均保留。仅在新开关开启时加载 `assets/collapsible-content-faq.css`、渲染 `snippets/collapsible-content-faq.liquid`。关闭时仍走原来的 Liquid、CSS 和布局路径。

新增样式全部限定于 `.collapsible-faq`，以实例 CSS 变量控制外观；没有修改 `component-accordion.css`、`collapsible-content.css`、全局 JS 或其他分区。交互使用原生 `details` / `summary`，支持鼠标、键盘、手机触摸以及编辑器重新插入，无需额外 JS。

## 设计与验证

- PC 节点 `6411:25605`：1920px，左右 200px、上下 80px，内容内边距 30px；标题 28px、问题 18px、回答 16px，问题组间距 40px。
- 移动节点 `6411:26148`：393px，左右 16px，上 24px、下 48px；标题 24px、问题 16px、回答 14px，问题组间距 20px。
- 加减号使用 Figma 导出的 24 × 24px SVG，以原图蒙版显示并继承问题颜色；没有手画或替换设计图标。
- 未预设设计稿问答内容或展开状态，避免影响原有配置。视觉验证以临时设计示例数据进行，PC 高约 1230px，移动高约 1024px（设计稿约 1023px，存在行高取整差异）。实际高度随真实内容和展开项变化。

验证覆盖 1920 / 1280 / 750 / 749 / 393 / 320px、两个问题同时展开、加减号资源、键盘与触摸、动态移除和重新插入、多实例颜色和间距、空内容、40 个长问题及减少动态效果。新开关关闭时，渲染输出与修改前逐项比对一致；默认样式的内部 / 外部标题与新样式同页时也保持原显示。Schema、设置引用、Theme Check 与空白检查通过，主题原有无关问题未改动。
