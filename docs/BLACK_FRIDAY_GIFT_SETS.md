# 黑五礼盒商品模块

在主题编辑器的「添加分区」中选择 **黑五礼盒商品模块**。本次实现只注册 section，不修改任何模板或现有页面。

## 配置方式

- 顶部图片可分别上传 PC 和移动端版本；移动图为空时回退 PC 图。两张都为空且启用默认图片时，使用从设计稿下载的 Flash Deal 原图。上传的图片采用完整展示，不应用原图专用裁切。
- 标题支持单行富文本，说明支持多段富文本。说明中的加粗文字在 PC 端映射为高亮色 / Merriweather；移动端按设计回到普通文字。颜色与标题光晕可调整。
- PC、移动端分别配置顶部图片尺寸、标题及说明的宽度、字号、行高、图片与标题间距、标题与说明间距、标题区与卡片间距、卡片间距及内容间距。商品标题、套装内容的字号与行高也可分别配置。
- 每个「商品卡片」block 填入一个实际 Shopify 礼盒商品的颜色版本链接；卡片可增删和排序，未设置人为数量限制。该礼盒内包含哪些商品由所选商品本身决定，不会把文案清单中的配件自动加入购物车。
- 商品标题留空时使用商品名称；套装内容支持列表与段落；每张卡片可独立上传 PC 和移动端商品图片：PC 优先使用上传的 PC 图片，否则使用绑定颜色的变体图，再回退商品默认主图；移动端优先使用上传的移动图片，再回退上述图片。所有图片以 Shopify 响应式图片输出并尊重对应焦点，不使用设计稿商品图片。
- 卡片的「展示售价」「展示划线价」均手动填写（包含货币符号），按原样显示，分别留空时不显示；不会读取商品价格，也不会随颜色切换变化。库存和购买状态继续读取所选变体。展示金额仅用于卡片，购物车和结账使用 Shopify 后台的实际商品价格。右上角优惠标识金额由每个商品卡片的「优惠标识金额」手动填写，例如 `$120`、`$100`；按原样显示，货币符号需自行填写。留空或关闭「显示优惠标识」时隐藏标识，切换商品变体不会修改其金额或显示状态。
- 未配置商品时，只在主题编辑器展示主题默认商品占位图和禁用的按钮；正式页面不会展示虚构商品或示例价格。
- 导航锚点默认 `gift-sets`，与黑五导航项的「目标锚点」一致即可关联。重复添加模块时，每个实例应使用不同锚点。

## 绑定颜色版本

每张卡片只需填写「颜色版本链接」，无需另外选择商品。打开商店商品页，选好颜色，复制带有 `?variant=...` 的完整地址粘贴即可，例如 `https://example.com/products/luna?variant=123456789`。

- 已填写：根据链接自动识别商品及其具体变体，库存、加购和立即购买均使用它；卡片价格使用手动填写内容；前台不再显示变体选择框。支持参数顺序不同、其他追踪参数、语言前缀、集合路径及链接片段。
- 图片顺序为「卡片自定义 PC 图 → 对应颜色变体图 → 商品主图」；移动端优先使用自定义移动图，再回退上述图片。
- 留空：可使用「备用商品」保留原有行为，多变体商品由顾客在前台选择。
- 链接缺少变体参数、包含重复变体参数、商品未发布或不存在，或变体不属于链接中的商品时，禁用购买，主题编辑器提示重新复制链接。
- 指定颜色缺货时显示已售罄，不替换为其他有货颜色。优惠金额继续使用手工配置。
- 原有设置键 `variant_id` 与 `product` 保留，旧数字 ID + 商品配置继续兼容；新增配置只需颜色版本链接。链接对应的商品优先于备用商品。
- 通过链接使用 Shopify `all_products` 查询商品；每页最多查询 20 个不同商品 handle（相同商品的多个颜色复用同一 handle），这是 Shopify 平台限制。已选择且与链接匹配的备用商品不会重复查询。

## 购买行为

「Add to cart」加入当前卡片绑定的颜色变体（未绑定链接时使用顾客选中的变体），成功后直接跳转当前语言的购物车页面，不打开购物车抽屉。请求期间锁定当前卡片，失败时显示 Shopify 返回的错误并允许重试。

「Buy Now」先加入所选变体，再跳转当前语言路径下的结账页。现有购物车内容继续参与结账。请求不包含其他模块中的配件选择。

必须选择订阅方案或最小购买量大于 1 的变体不直接购买，提供商品详情页入口。未加载 JavaScript 时保留 Shopify 原生商品表单提交。

## 复用标题区

标题区独立为 `snippets/black-friday-promo-heading.liquid`，对应样式为 `assets/black-friday-promo-heading.css`。

其他 section 可以加载该 CSS 并传入相同字段结构的设置对象：

```liquid
{{ 'black-friday-promo-heading.css' | asset_url | stylesheet_tag }}
{% render 'black-friday-promo-heading', config: section.settings %}
```

调用 section 需声明标题、说明、图片、颜色、两端尺寸与间距等对应 schema 字段；字段清单以 `sections/black-friday-gift-sets.liquid` 为准。共享 snippet 的变量和样式均限制在自己的根节点内。

## 设计与验证

- PC 完整模块：`6411:24707`，1920px，内容左右各 200px，卡片 1520 × 600px，左图 800px、右文 720px。
- PC 标题：`6411:24708`；移动标题：`6411:25782`。
- 从移动标题的父节点确认完整移动模块为 `6411:25781`，393px，左右各 16px；卡片上图下文，图片约 361 × 270px，优惠标识位于左上。
- 中间屏幕在 1440px 以下将商品卡片改为上图下文，避免优惠标识覆盖内容或图片严重裁切；1068px 以下 PC 内容左右间距调整到 32px。
- 移动设计复用了第一件商品的示例文案与价格；实现使用各卡片自身的文案、手动展示金额和商品绑定，PC / 移动端保持一致。文案区域随内容自然撑高。
- 本地验证包含 1920 / 1280 / 750 / 749 / 393 / 320px、静态资源、顶部图片回退、商品默认主图、长文案、空状态、多实例、变体、缺货、重复提交、加购失败及模拟结账。未向真实商店提交购物车或订单。
