# 黑五蝴蝶手链礼盒

在主题编辑器「添加分区」中选择 **黑五蝴蝶手链礼盒**。本次仅注册独立 section，未加入任何模板或现有页面。

## 配置

- 每张商品卡片只需填写选好颜色后的完整商品链接，包含 `?variant=...`，无需另外选择商品。该链接指定实际加入购物车的变体。
- 商品标题、展示售价、划线价、优惠标识金额均手动填写，金额包含货币符号，留空隐藏。不读取商品价格或自动计算优惠；卡片标题也不会回退商品标题。
- PC 与移动端共用一个「优惠标识金额」，填写一次即可；预设为 `$70`。留空或关闭标识时，两端均隐藏标识。
- 商品图片可按 PC、移动端分别上传。移动端优先使用移动图，否则使用 PC 自定义图，再回退链接对应变体图片和商品主图。没有下载或预设设计稿的商品图片。
- Add to cart 成功后进入购物车；BUY NOW 直接进入对应变体的商品详情页。缺货时禁用加购，详情入口仍可使用。无效变体链接不会被替换为其他颜色加购。
- 商品数据只用于解析变体、判断购买条件和图片回退。购物车与结账仍使用 Shopify 后台实际价格。
- 顶部图片可替换，移动图为空回退 PC。默认复用 Flash Deal 图片及 PC 星光装饰；装饰可关闭。PC 与移动端标题、说明分别配置，移动文案留空回退 PC。
- 字号、行高、颜色、图片与标题间距、标题与说明间距、标题区与卡片间距、卡片文案间距、PC 列间距与两端行间距均可设置；两端上下留白分别可调至 0。
- 导航锚点默认 `butterfly-gift-sets`，与黑五导航对应项目填写相同目标值即可。多个实例请使用不同锚点。

## 布局

- PC 节点 `6411:25337`：1920 × 1828px，左右 200px，上下 80px，标题区高约 174px；两列卡片，列间距 48px、行间距 40px。卡片 736 × 458px，左图 368 × 458px，右侧文字居中，按钮上下排列。
- 移动节点 `6411:26040`：393 × 1077.93px，左右 16px，上下 40px，标题区高约 264px；每行一张横向卡片，行间距 20px。卡片 361 × 224.64px，图片约 180.5 × 224.40px，右侧文字及上下按钮。
- 1440px 及以下采用一列横向卡片；1068px 及以下桌面侧边距 32px；749px 及以下使用移动样式。360px 及以下为右上优惠标识预留文案空间。
- PC 稿 6 张卡片、移动稿 3 张仅为设计示例。实际按 blocks 全部显示，不限制数量、不截断移动端内容。预设提供 6 张示例文案；正式页面仅显示已配置链接的卡片，编辑器中保留未配置卡片的占位图与提示。

## 文件与验证

入口为 `sections/black-friday-bracelet-sets.liquid`、`assets/black-friday-bracelet-sets.css`。标题区、优惠图形、商品卡片和变体交互复用现有组件；没有新增 JS 或图片资源。横向卡片通过 `card_layout: 'horizontal'` 区分，样式由本模块根类限定。

链接解析使用 Shopify `all_products`，每页最多查询 20 个不同商品 handle，同商品不同颜色复用同一 handle。这是平台限制，与 blocks 数量无关。

验证覆盖 1920 / 1280 / 750 / 749 / 393 / 320px、PC 与移动端金额一致性、图片覆盖与回退、空字段、长标题、33 张卡片、多实例、已有模块同页、缺货与无效链接、模拟加购及错误恢复、详情跳转、键盘、手机触摸与减少动态效果。没有向真实商店提交购物车或订单。变更文件执行 schema / 引用校验、JS 语法、Theme Check 和空白检查；历史主题问题不属于本次修改范围。
